“Who do I write with most?”

SELECT a.name, COUNT(*) AS shared

FROM authorships s

JOIN authors a USING (author_id)

WHERE a.author_id != :me

GROUP BY a.author_id

ORDER BY shared DESC, a.name;

Always show the SQL, never just the answer: the WHERE clause that excludes yourself is exactly the kind of line that goes missing. Follow-up questions that work well live: what did I publish in 2021 (five works), which venues, which of my works are open access. If the room is engaged, ask it to draft the publications section of an annual report as a markdown note, which is a Surface.

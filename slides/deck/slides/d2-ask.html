The payoff

Ask in English, read the SQL, check the answer

“Which countries have had the most coup attempts since 2020?”

SELECT country, COUNT(*) AS attempts,

  SUM(coup = 2) AS successful

FROM events

WHERE year >= 2020

GROUP BY country

ORDER BY attempts DESC, country;

Real output on release V2026.08.29: 21 attempts in 14 countries since 2020. Query run 2026-10-23.

This is the moment people want to try themselves. Always show the SQL, never just the answer: the WHERE clause is where errors hide (for example, year greater than 2020 instead of greater than or equal). Then join to the papers table: “for each of these, the three newest open-access papers.” If the room is engaged, ask it to write a one-paragraph weekly brief into a markdown note, which is a Surface.

Step 4 · Verify, every time it runs

A signal checks itself

Row counts

Rows fetched equal rows stored, logged per release.

Version stamp

Every row knows which release it came from.

Change report

A new release lists added, dropped, and recoded events.

Freshness alarm

Silent for too long means a broken feed, not a quiet world.

The harness wrote these checks. You decide the thresholds.

Freshness matters most: an empty table looks exactly like a world with no coups. The Field Guide has a freshness module for this. End Demo 2 by running the sync a second time to show it is idempotent: same release, zero new rows, and a change report that says nothing changed.

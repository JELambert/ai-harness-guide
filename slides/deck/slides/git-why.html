Why harnesses and Git belong together

Every edit is visible

The agent’s changes show up as a diff you read before keeping.

Every mistake is undoable

A commit before each step is a free undo button.

Every step has a reason

Commit messages become your methods log.

This is the bridge into the demos. Everything the harness does from here on will be committed, so we can show exactly what it changed and roll it back if it goes wrong.

Which file is really final?

Filenames cannot tell you which is authoritative, what changed, who changed it, or how to get the old one back.

coup_paper_final.docx

coup_paper_final_v2.docx

coup_paper_final_JL.docx

coup_paper_USE_THIS.docx

Everyone in an academic audience has lived this, especially with coauthors. Ask for a show of hands. Then make the point: when an AI tool starts editing your files, this problem gets worse unless every change is recorded.

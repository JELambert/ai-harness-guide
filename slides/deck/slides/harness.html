A model is an engine. A harness is the car.

The model predicts text. The harness decides what it can see, what it may change, and how the result gets checked.

Claude Code and Codex are two harnesses. Today is about the pattern, not the brand.

Spend time here. Most people’s mental model is a chat box. The point is that the same model behaves very differently depending on what files it can read, what instructions it carries, what tools it may run, and what it is forbidden to do. The gold chip is deliberate: checks and a human decision are part of the harness, not an afterthought.

The Field Guide pattern

Every file has a home, every module a job

Four planes: where it lives

vault/

Knowledge: notes

store/

Data: SQLite tables

modules/

Capability: code

governance/

Rules: definitions

Four contracts: what it does

Signal

Data in. Owns one store.

Surface

Shows it: a page, a note.

Action

Does something, with approval.

Governance

Defines the rules.

Today we build one Signal, and the People notes it feeds.

Keep this brisk. The audience does not need the whole architecture, only the idea that data lands in a small local database and notes stay in plain markdown, all in open formats on your own disk. The Field Guide is MIT licensed and public.

# Standing brief

This is the brief an AI harness reads every time it opens this folder. Claude Code reads `CLAUDE.md`, which points here; Codex reads this file directly. One brief, both tools.

## What this folder is

A workshop on working with AI harnesses, and the folder we work in during it.

- `slides.html`: the workshop deck. Open it in a browser.
- `handout.html`: the participant handout.
- `prompts.md`: every prompt used in the session.
- `semester/`: a sample faculty folder for one semester. Dr. Sam Rivera (fictional) teaches MGMT 340 at Example State University (fictional). Everything in it is synthetic or open access.
  - `inbox/`: emails saved as `.eml` files
  - `teaching/`: catalog text, last year's syllabus, the academic calendar
  - `research/`: papers (run `get-paper.sh` once to download the reading)
  - `data/`: spreadsheet exports
  - `notes/`: everything you write goes here

## How to work here

- Read the relevant files before answering. Say which files you used.
- Write new work to `semester/notes/` as plain markdown (or `.docx` or `.png` when asked). Never edit the files in `inbox/`, `teaching/`, `research/` or `data/`.
- Every date, number and claim you write points to the file it came from.
- If something is missing or unclear, say so plainly instead of guessing.
- Draft emails as files. Never send email, post, or publish anything.
- Before changing more than one file, say what you plan to do.
- Show me what changed when you finish.

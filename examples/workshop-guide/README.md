# Workshop guide demo

This is a fictional, public-safe example for the McNeese AI harness workshop. It is not an actual McNeese event. The goal is to revise `guide.md` from the facts in `brief.md` and `agenda.md`, then show a diff and verify each logistical claim.

Start by asking the assistant to read the brief and agenda without editing. Then request a bounded revision to `guide.md`. The existing draft deliberately contains unsupported claims to catch during review.

For the second demo, `attendance.csv` has a repeated participant ID. Compare a raw count of `yes` rows with a count of distinct attendees before accepting a summary.

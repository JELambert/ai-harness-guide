01 / Before you arrive

You can come with just a question.

This is a guided demonstration, not an installation contest. Bring a small, repeatable task you wish took less time. You can observe every exercise without an account or a terminal.

BRING

A low-stakes example

A checklist, public document, synthetic spreadsheet, or toy project is enough. Avoid confidential or student data in practice prompts.

NOTICE

One success check

What would prove the result is useful? Examples: no missing steps, correct totals, or a clear citation to source material.

OPTIONAL

Choose a tool

If you already use ChatGPT Desktop or Claude Desktop, bring your laptop and sign in. Otherwise, watch the same workflow on screen.

No tool purchase is required for the workshop. If you want to practice later, check your institution's account access and data policies before using real work material.

What is a harness?

A chat assistant answers from the context you provide. An AI harness adds a working environment: files, tools, permissions, and a path to inspect results. That lets it do more than suggest text, but it makes your review more important.

What stays yours?

The goal, the source material you permit, the decision to accept a change, and responsibility for the final result. A polished answer is not a verified answer.

03 / Practice the loop

One task, two passes

First ask the harness to understand the job. Then ask it to make a bounded change and show evidence.

Pass one: inspect

Use this with a small, non-sensitive folder or document.

Read the files relevant to this task. Do not edit anything yet. Summarize what is there, identify missing context, and propose the smallest useful next change. Tell me how we could verify it.

Pass two: act and verify

Adapt the brackets before sending.

Make only this change: [specific outcome]. Do not alter [boundary]. Show me what changed, then check it against [success criterion]. If you cannot verify something, say so clearly.

Inspect the result

  1. Compare before and after. Did it change only what you asked?
  2. Run the check or read the output. Are details and numbers supported?
  3. Ask what remains uncertain. Fix or reject weak work before sharing.

A good first task

Start with a reversible draft: improve a public event checklist, turn a rough agenda into a one-page outline, or summarize a synthetic dataset. A high-stakes decision, final grade, or external message needs a separate human check.

Exit ticket: What changed? How did you verify it? What would you keep under human control?

04 / Optional setup

Pick a path when you are ready.

You do not need both desktop apps. Download one if you want to try the workflow later; no installation is required to follow the workshop.

Download ChatGPT Desktop

Get the ChatGPT desktop app, sign in, and choose Codex for a project or folder. Start with the inspection prompt above, then review proposed file changes and permissions before continuing.

Download Claude Desktop

Get the Claude desktop app and sign in. Claude Code is available inside the app on eligible plans. Start with a small project folder, ask for an explanation before edits, and inspect what the tool proposes to do.

No setup today

Follow the guided demonstration, save the two prompts, and try them later on a non-sensitive example. You can learn the workflow before choosing a product.

Institutional data check: Before uploading or connecting real student, personnel, research, or financial material, check McNeese policy and the approved accounts available to you. The workshop examples use synthetic or public material.

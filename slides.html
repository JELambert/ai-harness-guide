The standing brief

Tell it once. It reads it every time.

A plain text file at the top of the folder: what this is, how you work, what it must never do. Claude Code reads CLAUDE.md, Codex reads AGENTS.md. This folder uses one for both.

Do not write it by hand. Tell the harness what matters and let it write the file. Caught yourself explaining something twice? “Add that to the brief.”

# AGENTS.md (from this folder) ## How to work here - Read the files before answering. Say which files you used. - Write new work to semester/notes/. Never edit the originals. - Every date and number points to the file it came from. - If something is unclear, say so. - Draft emails as files. Never send anything.

How to talk to it

More words, not fewer

Be specific

Name the file, the outcome, the format, the deadline.

Think out loud

Include the parts you are unsure about. Long and meandering beats short and clipped.

Speak, don’t type

Talking gets more words out than typing, and forces you to say what you actually mean.

Ask for pushback

“What am I missing?” and “Check this against the files” make the answer better.

Git and GitHub

Which file is really final?

Filenames cannot tell you what changed, who changed it, or how to get the old one back. Once an AI starts editing your files, that matters more.

syllabus_final.docx

syllabus_final_v2.docx

syllabus_final_Pat_edits.docx

syllabus_USE_THIS.docx

Git is the harness’s undo button

Three words, then let it drive

Repository

A folder that remembers its own history.

Commit

A named save point for the whole folder, with a reason.

Diff

Exactly which lines changed between two save points.

You never type the commands. You say “commit this” or “undo what you just did.” GitHub is the shared, backed-up copy, so keep it private unless it is meant to be public.

No single file could answer this. It took the email, the calendar, the syllabus and the survey together.

That is the point of one folder.

Beyond files

The folder can also reach out

Connectors

Claude and Codex can connect to Gmail, Google Drive, calendars and more, so you can ask “what did Pat send this week?” without saving anything first.

Start read-only

Let it read before you let it act. Anything that sends, deletes, books or buys stays your click.

Files first is the safe default: you choose exactly what goes in the folder.

Where it grows

One big folder, a growing network of context

Start with one folder for one semester. Over time, put everything under one roof: your Git repositories, your Obsidian notes, your PDFs, your diagrams. Open the harness at the top, and it can connect all of it.

Before you try this at work

Today was synthetic on purpose

Human-subjects data follows your IRB protocol.
Unpublished work and reviews held in confidence stay private.
